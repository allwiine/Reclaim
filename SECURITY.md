# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's
private vulnerability reporting instead:

**[Report a vulnerability](https://github.com/allwiine/Reclaim/security/advisories/new)**
(Security tab → "Report a vulnerability")

You'll get a response within a week, usually much faster (this is a
solo-maintained project). Please include reproduction steps and the app
version.

## Scope notes

Reclaim's whole job is deleting files, so bugs that could make it delete
something outside the scanned, user-confirmed selection — or anything the
catalogue classifies as user data — are treated as top-severity even though
they aren't classic security vulnerabilities. Report those the same way.
